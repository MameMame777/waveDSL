## v0.2.0 — Signal Attributes & Top-Level Blocks

### New Features

- **Signal attributes**: `period=N` and `phase=N` (integer or float) appended after wave sequences
- **`head` / `foot` blocks**: `text`, `tick`, `tock`, `every` key-value pairs for WaveDrom headers/footers
- **`config` block**: `hscale=N` for horizontal scaling
- **Float literal support**: `0.5`, `1.5` etc. in lexer/parser
- Blocks can appear in any order in source; parser dispatches by keyword

## v0.3.0 — Constants & Include

### New Features

- **`const` declarations**: `const NAME = value` defines a reusable constant
- **`$NAME` variable references**: Substituted at semantic analysis time
- **`include "path"` directive**: Pre-lexer file inclusion with circular reference detection
- **Preprocessor module** (`src/preprocessor.rs`): New compilation phase for include expansion

### Architecture Decisions

- **Preprocessor vs. Parser include**: Chose pre-lexer text expansion (like C `#include`)
  - Simpler: no AST node needed for include
  - Constants from included files available to including file
  - Circular reference detection via `HashSet<PathBuf>`
  - Max nesting depth = 16

- **Const resolution in semantic phase**: Constants resolved by walking AST after parsing, before validation
  - Two-pass: (1) collect const declarations into HashMap, (2) substitute `VarRef` nodes
  - Forward references prohibited (declaration-order resolution)
  - Reserved words (`signal`, `group`, `clock`, etc.) cannot be used as const names

- **`compile()` API change**: `compile(input, file_path)` — `file_path: Option<&Path>` added
  - Backward compatible: pass `None` for no-file usage (stdin, tests)

### Pitfalls Encountered

1. **`data` is a reserved signal name**: Used `signal data ...` in sample, got semantic error. Renamed to `signal bus`.
2. **`low(0)` is invalid**: n must be >= 1. Fixed sample to remove trailing zero-length signals.
3. **Snapshot acceptance workflow**: New insta snapshots require `cargo insta accept` before tests pass. Not a bug, just workflow.
