# Development Diary 2026-03-12

## Summary

Implemented signal attributes (`period`, `phase`) and top-level blocks (`head`, `foot`, `config`) for WaveDSL v0.2.0.

## Changes

### New Features

- **Signal attributes**: `period=N` and `phase=N` (integer or float) appended after wave sequences
- **`head` / `foot` blocks**: `text`, `tick`, `tock`, `every` key-value pairs for WaveDrom headers/footers
- **`config` block**: `hscale=N` for horizontal scaling
- **Float literal support**: `0.5`, `1.5` etc. in lexer/parser
- Blocks can appear in any order in source; parser dispatches by keyword

### Files Modified

| File | Changes |
|------|---------|
| `src/token.rs` | Added `Float(f64)`, `Head`, `Foot`, `Config` tokens |
| `src/lexer.rs` | Float parsing, new keyword recognition |
| `src/ast.rs` | `Float(f64)` in `Value`, `SignalAttr`, `KeyValue`, new `Program` fields |
| `src/parser.rs` | Lookahead refinement, `parse_signal_attrs()`, `parse_kv_block()` |
| `src/semantic.rs` | Validation for signal attrs, head/foot/config keys and types |
| `src/codegen.rs` | Emit `period`/`phase` on signals, `head`/`foot`/`config` at top level |
| `wavedsl-spec.md` | Updated EBNF, added Sections 5.5-5.6, 7.1-7.3 |

### Test Results

- 55 unit tests + 7 snapshot tests = 62 total, all passing
- `cargo clippy` clean
- Full backward compatibility with v0.1.0

### Key Design Decisions

1. `head`/`foot` allow all valid keys (`text`, `tick`, `tock`, `every`) in both blocks
2. Integer/float emitted as written in JSON
3. Any ordering of head/foot/config in input allowed
